Coupon Keeper Source code

Use your coupon codes before they expire.

A browser extension that holds the codes stores email you and reminds you five days before each one runs out. It never sees the sites you visit.

Add to Chrome Add to Firefox
NO-TRACKING

Works in Chrome and Firefox. Free.

Save it once, find it at checkout

When a store sends you a code, add it with the store name, the expiry date and any fine print, like a minimum order. Your coupons are sorted by whichever runs out first.

Five days before a code expires, you get one notification with the code in it. At checkout, open the popup and copy it with one click.

Codes that have run out move to an Expired list instead of disappearing, so you can delete them when you're ready.

What it can't do

Most coupon extensions find deals by watching where you shop. This one only knows what you type into it.

  • It can't see the sites you visit. It doesn't ask for access to any website, so the browser won't let it read pages.
  • It doesn't connect to the internet. Your coupons are stored in your browser and never sent anywhere.
  • It has no account. No sign-up, no email address, nothing to link back to you.

You don't have to take our word for it. The only permissions it requests are storage, alarms and notifications, which your browser shows before you install. The source code is public. Read the privacy policy for the details.
